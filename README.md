# 静屿 Quietly

一个看起来很正常的冥想 App 官网。请慢慢往下滚动，并戴上耳机。

纯静态页面，无构建步骤，直接用 GitHub Pages 发布：

1. 把本目录所有文件（包括 `.nojekyll`）推到仓库根目录的 `main` 分支
2. 仓库 Settings → Pages → Build and deployment → Source 选 **Deploy from a branch**，分支 `main`，目录 `/ (root)`
3. 稍等 1～2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`

素材为网络流传的「奶龙捧腹大笑」表情包与 B 站音效，仅供娱乐，非商业用途。
